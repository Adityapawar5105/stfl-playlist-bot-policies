# Privacy Policy — STFL Playlist Bot

Last updated: September 22, 2026

STFL Playlist Bot is a Reddit application designed to create Spotify playlists from music recommendations shared in Reddit communities.

## Information the Bot Processes

The bot may process:

- Reddit post IDs
- Reddit post titles and content
- Reddit comments
- Comment text containing song recommendations
- Spotify track information
- Spotify playlist information

The bot uses this information only to identify music recommendations and create community playlists.

## Spotify Information

The bot uses Spotify's Web API to search for songs and create public playlists.

Reddit users are not asked to provide their Spotify login credentials to the bot.

The bot's Spotify authorization credentials belong to the application operator and are stored securely. They are not collected from Reddit users.

## Data Storage

The bot uses Redis to record Reddit posts that have already been processed. This is used to prevent duplicate playlist creation.

The bot does not intentionally store users' personal information for profiling or advertising.

## Third-Party Services

The application interacts with:

- Reddit
- Spotify

These services have their own privacy policies and terms.

## Data Sharing

The bot does not sell Reddit users' personal information.

Music recommendations are sent to Spotify's API when necessary to search for matching tracks and create playlists.

## Data Retention

Processed-post information may be retained in the application's Redis storage to prevent the same Reddit post from being processed repeatedly.

## Changes to This Policy

This privacy policy may be updated when the application's functionality changes.

## Contact

For questions regarding this application, contact the application operator through the Reddit community where the bot is installed.
